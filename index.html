Faithful to the text, by design.

This reader passes your reviewed text directly to a speech engine. It has no chat model, prompt, rewrite, or “improve” step. Numbers and abbreviations are spoken according to the voice engine. Speech synthesis can still mispronounce, omit, or repeat words; this is not a guarantee of perfect spoken accuracy. Review important passages by listening alongside the text.

Natural voices run locally using Kokoro (Apache-2.0 model). First use downloads roughly 100–330 MB of model weights plus runtime files; allow extra time and use Wi-Fi. Supported browsers use GPU acceleration. CPU-only creation can be much slower than playback; use a computer for long sermons. Keep the page awake while creating audio. English text supported. Scanned PDFs need text copied from another source.
