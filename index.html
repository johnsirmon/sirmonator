A little more epic. Still your original message.
The Sirmonator passes your reviewed text directly to a speech engine. No chat model, prompt, rewrite, or “improve” step. Natural delivery respects sentence and paragraph boundaries and adds silent pauses. Numbers and abbreviations follow the voice engine’s pronunciation rules. Speech synthesis can still mispronounce, omit, or repeat words; perfect spoken accuracy is not guaranteed. Review important passages alongside the text.
26 free studio choices: ten Supertonic 3 narrators, fourteen Kokoro classics, and two reference-conditioned character impressions using Kyutai Pocket TTS (CC-BY-4.0 model assets). They are unofficial impressions; resemblance varies. Supertonic’s code is MIT; its archived model is OpenRAIL-M. Kokoro’s model is Apache-2.0. Auditions use small audio samples. MP3 encoding uses lamejs / LAME under LGPL-3.0, supplied as a separate replaceable module with license notice. Drafts and recordings are saved in this browser when enabled and can be deleted from the reader. Full sermon generation first downloads roughly 100–400 MB plus runtime files per engine. Use Wi-Fi, keep this page open, and use a computer for long sermons. English supported. Scanned PDFs need text copied from another source.
